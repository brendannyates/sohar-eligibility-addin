Clinic files and emails

One file per location for the clinic team: patients with an upcoming visit, benefits, flags and a re-verify link. Opening it in Excel shows the Clinic tab, where the clinic ticks Re-verify anyway for patients the skip window left out. The email summary uses LASFIR and MRN only.

Clinic Template Tool file: the same clinic's patients for the Clinic Template Tool, which opens it on its own. Patients show as LASFIR and MRN (no names or dates of birth). The clinic ticks tasks done (with a note if it wants), asks for a re-verify and adds patient or payer notes. Put the file in the clinic's folder in the Clinic Eligibility library: the clinic inbox below picks up its changes. Without the inbox, the clinic sends the file back.

Clinic files and Clinic Template Tool files contain PHI. Share them only through MHS OneDrive or Teams with the clinic team; do not email them outside MHS.

Esketamine payer rules

Which payers let an NP or an MD bill each esketamine visit (first treatment, start, observation), and which are Besse-approved. Import Payer Credential Rules.csv from the Add-In Manifests folder in OneDrive; it goes on the Payer Credential Rules sheet, which you can edit in Excel. Upcoming ESK visits are checked against it on every refresh. No sheet, no check.

Payer learning

Appointments whose payer is unmapped or whose verification failed, by NextGen payer, with payer test results and guarantor search themes. Full screen has the whole list.

Shows after the NextGen report is loaded.

Payer evidence

Every refresh adds what was seen to the Payer Evidence sheet: NextGen payer, member ID prefix, location, ZIP3 and what Sohar returned. Over time it shows which Sohar payer a one-off NextGen name really is.

IR Portal cross-check (optional)

Upload the IR Portal workbook (its Filtered tab) or a CSV of it. Insurance items are matched to the Sohar results by MRN, then name and DOB, and written to IR Cross-Ref.
